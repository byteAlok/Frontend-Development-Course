## 🌟 About The Course

Welcome to the **Frontend Development Course** repository! 🚀

This repository contains all the source code, projects, notes, and exercises for learning modern frontend web development.

Throughout this course, you will learn frontend development step by step through:

- 📖 Concept-based learning
- 💻 Hands-on coding
- 🧩 Practical exercises
- 🚀 Real-world projects
- 📝 Notes and examples

## 🚀 Getting Started

Follow the steps below to clone and run this repository on your local machine.

### 📋 Prerequisites

Before getting started, make sure you have the following installed:

- [Git](https://git-scm.com/)
- [Visual Studio Code](https://code.visualstudio.com/)
- A modern web browser such as Chrome, Edge, or Firefox
- **Live Server** VS Code extension (recommended)

### 1. Clone the Repository

Open your terminal or command prompt and run:

```bash
git clone https://github.com/byteAlok/Frontend-Development-Course.git
```

### 2. Navigate to the Project Directory

```bash
cd Frontend-Development-Course
```

### 3. Open the Project in VS Code

If you have VS Code installed and the `code` command is available, run:

```bash
code .
```

Alternatively, you can open the `Frontend-Development-Course` folder manually in VS Code.

### 4. Run the Projects

For HTML, CSS, and JavaScript projects, it is recommended to use the **Live Server** extension in VS Code.

After installing Live Server:

1. Open the required `.html` file.
2. Right-click inside the file.
3. Select **Open with Live Server**.
4. The project will open automatically in your browser.

### 🔄 Pull Latest Changes

If you have already cloned the repository and want to get the latest changes:

```bash
git pull origin main
```

## 🤝 Contributing

Contributions, issues, and feature requests are welcome! ❤️

If you would like to improve the course materials, fix an issue, or add new exercises, feel free to contribute.

### Contribution Steps

#### 1. Fork the Repository

Create your own fork of this repository on GitHub.

#### 2. Clone Your Fork

```bash
git clone https://github.com/YOUR-USERNAME/Frontend-Development-Course.git
```

#### 3. Navigate to the Project Directory

```bash
cd Frontend-Development-Course
```

#### 4. Create a New Branch

```bash
git checkout -b feature/NewExercise
```

#### 5. Make Your Changes

Add your improvements, exercises, examples, or fixes.

#### 6. Commit Your Changes

```bash
git add .
git commit -m "Add new Flexbox exercise"
```

#### 7. Push Your Branch

```bash
git push origin feature/NewExercise
```

#### 8. Open a Pull Request

Go to your forked repository on GitHub and create a **Pull Request** to the original repository.
